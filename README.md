# Amazon India Sales Dashboard

## Project Overview

This project focuses on building a simple, easy-to-understand management
dashboard for Amazon India sales data. The dashboard is intended to help
business stakeholders review sales, profit, products, orders, payment
methods, fulfilment, and geographic performance in one place.

The project was completed as part of the **Sapphire IQ Business
Analytics** program.

## Business Objectives

The dashboard is organized around four business objectives:

### 1. Overall Sales & Profit Performance

-   Total sales
-   Total profit
-   Total orders
-   Total units sold
-   Average Order Value (AOV)
-   Profit margin
-   Overall business performance indicators

### 2. Category & Product Performance

-   Category-wise sales
-   Category-wise profit
-   Category-wise units sold
-   Top 10 products by sales

### 3. Order Status & Revenue Loss

-   Delivered, shipped, returned, and cancelled orders
-   Return rate
-   Cancellation rate
-   Category-wise returns and cancellations

### 4. Payment, Fulfilment & Geographic Performance

-   Sales and profit by payment method
-   Sales and profit by fulfilment method
-   State-wise sales
-   State-wise profit
-   State-wise orders

## Tools Used

-   Microsoft Excel
-   PivotTables
-   Charts and dashboard visualizations

## Repository Contents

-   `Amazon Sales Data India Dashboard.xlsx` --- Excel workbook
    containing the sales data, objective-wise analysis, PivotTables,
    charts, and dashboard.

## How to View the Project

1.  Open the Excel workbook from this repository.
2.  Download it if you want to interact with the workbook in Microsoft
    Excel.
3.  Open the `Dashboard` worksheet to view the dashboard.
4.  Review the objective-wise worksheets for supporting analysis.

## Project Deliverable

The main deliverable is the Excel-based Amazon India Sales Dashboard.
